    Scent families

    Groups found automatically by comparing every perfume's notes. Each family is named after the notes it has most.

    How it works

    Every perfume's name and notes were turned into a vector (a list of numbers that captures meaning) with Google's Gemini embedding model.

    Your words are turned into a vector the same way, and the closest perfumes are shown first. Arabic and English share the same space, so both languages work.

    If the embedding service is unavailable, the site switches to keyword matching so search keeps working.
